IRONLOG — ANDROID HOME-SCREEN GYM TRACKER

WHAT'S INCLUDED
- Four-day Push / Pull / Legs / Abs programme
- Individual weight and reps entry for every set
- Local autosave, workout history with expandable exercise / set / weight / reps detail, and basic progress totals
- JSON backup export/import
- Offline app shell after first successful load

IMPORTANT
The app stores workout entries in the browser storage on this device. They are not synced to ChatGPT or another device. Export backups regularly.

HOW TO PUT IT ON YOUR ANDROID HOME SCREEN
1. Publish the contents of this folder to a static HTTPS website (for example, a GitHub Pages site).
2. Open the published HTTPS address in Chrome on your Android phone.
3. Open Chrome's three-dot menu and choose "Install app" or "Add to Home screen".
4. Confirm. IronLog will appear as an icon on your home screen.

GITHUB PAGES QUICK ROUTE
1. Sign in to GitHub and create a new public repository named ironlog.
2. Upload index.html, manifest.webmanifest, sw.js, icon.svg and README.txt to the repository's root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the site address to appear, open it on your Android phone, then install it from Chrome.

This is a static app; it does not need a server or account. Keep the repository public if using the free GitHub Pages option. Do not put private information in the repository.

12-WEEK PROGRESSION UPGRADE
- Programme week is calculated automatically from the start date.
- Set the start date to the Monday of your first training week in Programme.
- Weeks 1–2 establish baseline loads and technique.
- Weeks 3–6 and 8–12 guide progressive overload using previous logged performance.
- Week 7 automatically halves planned working sets (rounded up) as a deload.
- Previous logged weights/reps are shown beside each exercise to guide the next session.
- Existing workout history is preserved because the storage key remains ironlog_v1.
- Service-worker cache is versioned to v3 so the updated app can install cleanly.
